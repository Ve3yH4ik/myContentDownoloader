# Реєстр макросів

Єдине програмне джерело специфікацій: `src/core/macros.ts`. Наведений синтаксис — власний формат UDD v1; сумісність CDX1 не підтверджена.

| Назва | Синтаксис | Параметри / контекст | Default | Приклад | Стан |
|---|---|---|---|---|---|
| VALUE | `[VALUE]` | Поточний рядок результату (JSON-рядок) | порожній текст | `Дані: [VALUE]` | Працює |
| COUNT | `[COUNT]` | Кількість рядків | 0 | `[COUNT] рядків` | Працює |
| INDEX_ID | `[INDEX_ID]` | Індекс рядка, від 1 | 1 | `[INDEX_ID]. [VALUE]` | Працює |
| BOUNDARY | `[BOUNDARY:id]` | ID кореневої границі, joined | порожній текст | `[BOUNDARY:title]` | Працює; невідомий ID — помилка |

Підстановка одноразова: текст, отриманий із документа, не виконується повторно як макрос. Невідомий токен у квадратних дужках викликає помилку.

## Заплановані категорії

Отримання даних; границі; текст/Regex; HTML/CSS/XPath; JSON/XML; CSV; математика; логіка; змінні/лічильники; файли/зображення; HTTP/браузер; документи; черги/потоки; БД; користувацький код; AI.

## Оператори, що потребують специфікацій

`[IF]`, `[IF2]`, `[CHECKCHANGES]`, `[ADDFINALDOCUMENT]`, `[RELOADDOCUMENT]`, `[MORE_THREADS]`, `[WAIT]`, `[SETCOOKIES]`, `[FILTERSTRINGS]`, `[LINEMODE]`, `{skip}`, `{get}`, `{case_down}`, `{reset_if_nil}`, `{break_if_nil}`, `{SETVARIABLE}`.

Для них ще немає підтверджених граматик, параметрів, default, escape-правил і результатів оригіналу. До впровадження: записати приклад оригіналу → очікуваний результат → AST → валідатор → виконавець → тести проміжних значень. Не трактувати JSON Replace pipeline як парсер CDX1. Текст правил CDX1 зараз не приймається; невідомі типи pipeline відхиляє схема.
