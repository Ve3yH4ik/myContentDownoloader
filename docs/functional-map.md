# Функціональна карта

Джерело: надане користувачем ТЗ Universal Data Downloader та доповнення Advanced Text Processing, 2026-11-11. Скриншоти, файли оригінальної програми та її документація не надані. Аналіз візуальної та синтаксичної сумісності очікує джерел.

| Область | Етап 1 | Наступні етапи |
|---|---|---|
| Вхідні дані | Один HTTP(S) URL, UTF-8, GET, тайм-аут, ліміт 5 MiB | Черги, API-авторизація, JSON/XML/CSV/файли/БД |
| Границі | between, Regex (перша capture group), CSS (inner HTML), repeat, children | XPath/JSONPath, посилання SOURCE, умови |
| Вкладеність | Звичайні й повторювані у будь-якій комбінації; без заданого ліміту глибини | Захист від надмірної глибини/обсягу без мовчазного обрізання |
| Вибір результатів | enabled, ID, reverse → skip → max, min, separator | Окремі роздільники циклів, масиви/об'єкти |
| Обробка | Керований масив pipeline, Replace literal/Regex, trim, HTML→text, lower, singleLine, prepend/append/fallback/required/trimEndCharacters | Transliterate, shuffle, AST правил CDX1 |
| Виведення | Таблиця, JSON, CSV, текстовий шаблон | Візуальний JSON/XML/CSV-конструктор |
| Журнал | HTTP-статус/обсяг, значення до/після, тривалість кожної операції | Breakpoints, логи браузера, змінні |
| Проєкти | SQLite, ручне збереження окремих версій і повторне відкриття | Автозбереження, переносний формат, recovery/queue resume |
| UI | React/Electron, редактор JSON, результати, запуск/зупинка, експорт | Monaco, панелі, меню, React Flow, пауза/продовження |
| Браузер / БД / код / AI | Не реалізовано | Окремі перевірені етапи |

Початковий UI свідомо використовує редактор конфігурації. Відсутні функції не мають фіктивних кнопок. JSON-конфігурація зберігає всі налаштування реалізованих дій. URL над редактором має пріоритет над url усередині JSON.
